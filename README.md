# AIML Honors Assignments

This repository contains Python assignments focused on Object-Oriented Programming (OOP), file handling, relational database CRUD operations, Pandas data manipulation, and Python decorators.

## Assignments Overview

| Assignment | File Name | Description |
| --- | --- | --- |
| **Assignment 1** | [`payment_gateway_system.py`](/MananBalpande07/AIML-Honors-Assignments/blob/main/payment_gateway_system.py) | Multi-gateway payment processing engine built using OOP principles (Abstraction, Inheritance, Polymorphism). |
| **Assignment 2** | [`employee_csv_manager.py`](/MananBalpande07/AIML-Honors-Assignments/blob/main/employee_csv_manager.py) | Command-line Employee Management System implementing CRUD operations with persistent CSV file storage. |
| **Assignment 3 (SQLite)** | [`employee_sqlite_manager.py`](/MananBalpande07/AIML-Honors-Assignments/blob/main/employee_sqlite_manager.py) | Employee Management System implementing relational CRUD operations using Python's built-in `sqlite3` module. |
| **Assignment 3 (MySQL)** | [`employee_mysql_manager.py`](/MananBalpande07/AIML-Honors-Assignments/blob/main/employee_mysql_manager.py) | Employee Management System connected to a MySQL database server using `mysql-connector-python`. |
| **Assignment 4** | [`employee_pandas_manager.py`](/MananBalpande07/AIML-Honors-Assignments/blob/main/employee_pandas_manager.py) | Employee Registry System implementing CSV-backed CRUD operations using the `pandas` library. |
| **Assignment 5** | [`function_decorators_toolkit.py`](/MananBalpande07/AIML-Honors-Assignments/blob/main/function_decorators_toolkit.py) | Custom parameterized and stacked Python decorators (`@trace_execution`, `@measure_latency`) for execution logging and benchmarking. |

## Tech Stack
* **Language:** Python 3
* **Storage & Databases:** CSV, SQLite3, MySQL (`mysql-connector-python`)
* **Libraries & Modules:** `pandas`, `functools`, `time`
