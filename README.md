# AIML Honors Assignments

This repository contains Python assignments focused on Object-Oriented Programming (OOP), file handling, and relational database CRUD operations.

## Assignments Overview

| Assignment | File Name | Description |
| :--- | :--- | :--- |
| **Assignment 1** | [`payment_gateway_system.py`](./payment_gateway_system.py) | Multi-gateway payment processing engine built using OOP principles (Abstraction, Inheritance, Polymorphism). |
| **Assignment 2** | [`employee_csv_manager.py`](./employee_csv_manager.py) | Command-line Employee Management System implementing CRUD operations with persistent CSV file storage. |
| **Assignment 3** | [`employee_sqlite_manager.py`](./employee_sqlite_manager.py) | Employee Management System implementing relational CRUD operations using Python's built-in `sqlite3` module. |
| **Assignment 4** | [`employee_mysql_manager.py`](./employee_mysql_manager.py) | Employee Management System connected to a MySQL database server using `mysql-connector-python`. |

## Tech Stack
* **Language:** Python 3
* **Storage & Databases:** CSV, SQLite3, MySQL
